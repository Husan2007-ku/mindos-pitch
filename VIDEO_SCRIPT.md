# MindOS — demo-video skripti (≈ 4 daqiqa)

**Yozish:** OBS Studio yoki Windows `Win + Alt + R` (Xbox Game Bar), 1920×1080, mikrofon yoqilgan.
**Tayyorgarlik (yozishdan oldin):**
- Yangi test akkaunt oching (masalan `demo+pitch@...`) — toza dashboard bo'lsin.
- Kichik IELTS PDF tayyorlab qo'ying (Speaking Part 1 savollari, 1–2 bet).
- Telegram'da botni akkauntga bog'lab qo'ying, kunlik eslatmani oldindan bitta yuborilgan holatda saqlang.
- Brauzerni 110% zoom, bookmarks bar yashirilgan, bildirishnomalar o'chiq.
- AI javoblari kutilishi mumkin — kutish joylarini montajda qisqartiring (bu soxtalashtirish emas).

**YouTube:** "Unlisted" qilib yuklang → ID'ni `site/assets/config.js` → `video.youtubeId` ga qo'ying.
