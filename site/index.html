    MindOS production'da ishlayapti: ro'yxatdan o'tish, diagnostika, reja, dars, uy vazifa, takrorlash, Telegram bot va ochiq API. Har bir funksiya haqiqiy foydalanish jarayonida sinalgan.

    Takrorla_Bot (spaced repetition Telegram boti) va Develop UZ (IELTS Writing/Speaking platformasi) — shu muammoni turli tomondan yechib, tajriba to'plaganmiz. MindOS — ularning eng yaxshi g'oyalari bir joyda.

    API Access

    MindOS'ning barcha funksiyalari ochiq REST API orqali ishlaydi. Hujjatlar interaktiv — brauzerdan sinab ko'rish mumkin.

    Swagger hujjatlarini ochish

    Base URL: https://mindos-api-dkq5.onrender.com

    • /api/v1/auth — ro'yxatdan o'tish, login, JWT refresh
    • /api/v1/onboarding — AI diagnostika va reja yaratish
    • /api/v1/curricula, /lessons — reja va darslar
    • /api/v1/chat — Mentor, Code Mentor, ovoz, TTS
    • /api/v1/sources — fayl/YouTube yuklash, manbadan so'rash
    • /api/v1/spaced-repetition — takrorlash kartochkalari
    • /api/v1/progress, /gamification — progress, XP, sertifikat

    Autentifikatsiya: Authorization: Bearer <access_token>

    # 1. Ro'yxatdan o'tish → access_token
curl -X POST https://mindos-api-dkq5.onrender.com/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","password":"StrongPass123","lang":"uz"}'

# 2. Diagnostika testi
curl -X POST https://mindos-api-dkq5.onrender.com/api/v1/onboarding/diagnostic/generate \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"topic":"IELTS Speaking"}'

# 3. Mentor bilan suhbat
curl -X POST https://mindos-api-dkq5.onrender.com/api/v1/chat/message \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"message":"Present Perfect qachon ishlatiladi?"}'
